# Internationalization

Six languages ship: English, Deutsch, Español, Français, Italiano, Português.

To add one:

1. Add an enum value in `source-frontend/main.c` (`LANG_*`).
2. Add a row to `dict[LANG_COUNT][T_COUNT]` (keep `T_COUNT` in sync).
3. Add a menu item in the top-bar language menu (alphabetical order for
   non-English languages).
4. Map the code in `save_settings` / `load_settings`.
5. Add the native name to the menu item label.

All user-facing strings and identifiers are in English.
